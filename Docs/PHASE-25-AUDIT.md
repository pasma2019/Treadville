## 3. FAVICON / ICON AUDIT

Next.js 16 supports `app/icon.png` and `app/favicon.ico` conventions. Currently neither is present.

The `OrganizationJsonLd` references `/icon.png` from the root, not `/favicon.ico`. To match the existing reference and Next.js convention:
- Create `/src/app/icon.png` — Next.js auto-generates `<link rel="icon" href="/icon">`
- OR: Create `/public/icon.png` (referenced in JSON-LD) — manual `<link rel="icon">` not added

Best approach: create `/public/icon.png` so the JSON-LD reference resolves correctly.
